# Глоссарий eat-easy

Версия: v1, 29.09.2026

| Термин | Что значит |
|---|---|
| Даркстор | Склад-магазин без покупателей. Обслуживает одну зону доставки |
| SKU | Товарная позиция: один товар в одной фасовке |
| Остаток (`on_hand`) | Сколько штук товара физически лежит на полке в дарксторе |
| Резерв (`reserved`) | Сколько штук уже обещано заказам, но ещё не собрано |
| Доступный остаток | Остаток минус резерв. Его видит покупатель в каталоге |
| Заказ | Набор позиций из одного даркстора на один адрес |
| Сборщик | Сотрудник даркстора, который собирает заказ |
| Курьер | Везёт собранный заказ покупателю. Один заказ за раз |
| Диспетчер | Сотрудник поддержки. Разбирает заказы, с которыми возникла проблема |
| Оффер | Предложение курьеру взять заказ. Действует 30 секунд |
| Назначение | Курьер принял оффер и закреплён за заказом |
| PSP | Платёжный провайдер. Проводит оплату картой, данные карт в систему не попадают |
| Холд | Деньги заблокированы на карте, но ещё не списаны |
| Списание | Деньги сняты с карты. Сумма — по тому, что действительно собрали |
| Вебхук | PSP сам вызывает наш API, когда статус платежа меняется |
| ТУС | Товароучётная система сети. Оттуда приходят товары, цены и поставки |
| Idempotency-Key | Заголовок запроса. Повтор с тем же ключом не создаёт второй заказ |
| p95 | Время, в которое укладываются 95% запросов |
| RPO / RTO | Сколько данных можно потерять при аварии / за какое время нужно восстановиться |
| correlation-id | Идентификатор запроса. Передаётся между сервисами и пишется в логи, по нему собирается путь запроса |
